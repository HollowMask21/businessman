# Businessman 💼

**Businessman** — это мобильное Android-приложение для внутреннего управленческого и финансового учета, контроля продаж, закупок и анализа товарных остатков. Приложение оптимизировано для работы на планшетах (Android 14+, API 34).

---

## 🚀 Основные возможности

- **Авторизация и роли:** Разграничение прав доступа для пользователей (`ADMIN`, `WORKER`).
- **Управление каталогом:** Единый справочник товаров (`PRODUCT`) и сырья/материалов (`MATERIAL`).
- **Финансовый учет:** Регистрация продаж (`SALE`), закупок и расходов (`PURCHASE`/`EXPENSE`) с ручным вводом и детальными позициями.
- **Умный импорт Excel:** Загрузка ведомостей `.xlsx` с автоматическим распознаванием колонок, нормализацией дат и разрешением конфликтов.
- **Офлайн-режим:** Синхронизация данных с облаком и поддержка полноценной работы без сети.

---

## 🛠 Стек технологий и библиотека

- **Язык:** [Kotlin]
- **Интерфейс:** [Jetpack Compose] (Material 3)
- **Архитектура:** Clean Architecture / MVVM (`ViewModel`, `StateFlow`, `Coroutines`)
- **Бэкенд и облако:** [Google Firebase] (`Cloud Firestore`, `Firebase Auth`)
- **Работа с файлами:** Apache POI (`poi-ooxml`) для парсинга `.xlsx`
- **Целевая платформа:** Android 14+ (API Level 34)

## 📊 Формат Excel для импорта

При импорте файла `.xlsx` приложение автоматически находит следующие ключевые столбцы:
* **Товар / Материал / Наименование**
* **Цена / Себестоимость**
* **Количество / Объем**
* **Сумма / Итого** *(опционально)*
* **Дата** *(опционально)*
